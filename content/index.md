ArchMap описывает программную систему деревом объектов произвольной глубины: от системы в целом до отдельного сервиса и его частей. Каждый уровень дерева — схема со связями; у каждого объекта — страница с документацией, спецификацией и фактами из кода.

## Работа с ИИ-агентом

К ArchMap можно подключить ИИ-агента по протоколу MCP. Агент работает с документацией проекта напрямую:

- читатель задаёт агенту вопросы об устройстве системы, и агент отвечает по документации проекта (см. [Задать вопрос о системе ИИ-агенту](user/agent-ask.md));
- архитектор поручает документирование сервисов агенту с доступом к исходному коду системы, и агент сразу записывает результат в ArchMap (см. [Подключить своего агента через MCP-сервер](architect/mcp.md)).

::: note Бета-функция
Документирование через ИИ-агента пока работает в режиме бета-версии. Результат агента нужно проверять, а ошибки иногда исправлять вручную.
:::

## Руководства

Документация поделена по ролям. Выберите руководство в дереве слева или воспользуйтесь поиском вверху страницы.
