::: note
Administrators see every project in ArchMap, including private and archived ones, and act as the owner in each of them. This helps when a project's owner isn't available (for example, they've left the company or been blocked).
:::

## Transfer a project to another owner

To transfer someone else's project to another architect, follow these steps:

1. On the **Projects** screen, click **⋯** on the project card.
2. Select **Access**. The **Project access** window opens.
3. In the owner's row, click **Transfer ownership**.
4. In the **New owner** field, select a user.
5. Click **Transfer**. A confirmation window opens.
6. Click **Transfer**.

::: note
The previous owner stays in the project as an editor. If they should no longer see the project, remove them from the members in the same window (see [Change a member's role or remove a member](../architect/access.md#member)).
:::

::: note
You can transfer ownership only to a user with the Architect account role. Before you change an architect's role to Viewer, transfer all their projects, because a user who owns projects can't be downgraded.
:::

## Restore a project from the archive

To restore a project from the archive, follow these steps:

1. On the **Projects** screen, open the **Archive** tab. It shows the archived projects of all users.
2. Click **⋯** on the project card.
3. Select **Restore**. A confirmation window opens.
4. Click **Restore**.

::: note
In the same way, an administrator can archive, permanently delete, or rename a project, or make it visible to all users (see [Archive, restore, or delete a project](../architect/archive.md), [Share a project and assign roles](../architect/access.md)).
:::
