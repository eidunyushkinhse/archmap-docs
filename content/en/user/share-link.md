::: note
Every project and object page has a permanent URL. The root level of the diagram is shown on the project page, and other levels on object pages (see [Navigate between diagram levels](levels.md)).
:::

## Copy a link

To share a link, follow these steps:

1. Open the page you want to share:
    - the project page, to share the root level;
    - an object page, to share the object at its level along with its documentation.
2. Copy the URL from your browser's address bar.
3. Send the URL to the recipient.

::: note
The recipient can open the page only if they have access to the project, either as a member or because the project is visible to all users. Otherwise, they see **Not found — the object may have been deleted or the link is out of date**.
:::

::: note
If the recipient isn't signed in to ArchMap, they are asked to sign in first, and then the shared page opens.
:::

::: note
Business processes don't have links of their own. Share the project link and tell the recipient the process name: they can open it with the **Processes** button (see [View a business process](processes.md)).
:::

::: note
The diagram view (**As is**, **Transition**, or **To be**) isn't part of the link: the recipient sees the view selected in their own browser.
:::
