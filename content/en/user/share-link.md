::: note
Every project and object page has a permanent address that opens the same page. The root level of the diagram is shown on the project page, and the other levels on object pages (see [Navigate diagram levels](levels.md)).
:::

## Copy a link

To share a link, follow these steps:

1. Open the page you need:
    - the project page, to show the root level of the diagram;
    - an object page, to show the object at its level together with its documentation.
2. Copy the address from the browser's address bar.
3. Send the address to the recipient.

::: note
The recipient sees the page only if they have access to the project: they are a project member or the project is open to all users. Otherwise, instead of the page, they see the message **Not found — the object may have been deleted or the link is out of date**.
:::

::: note
If the recipient is not signed in to ArchMap, the sign-in page opens first, and the page you shared opens after they sign in.
:::

::: note
A business process has no link of its own. Send a link to the project and name the process: the recipient opens it with the **Processes** button (see [View a business process](processes.md)).
:::

::: note
The diagram view (**As is**, **Transition**, **To be**) is not part of the link: the recipient sees the diagram in the view selected on their side.
:::
