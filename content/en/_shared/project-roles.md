## Project roles {#project-roles}

Each project member has one of three roles. A role applies only within its project: in another project, the same person can have a different role.

| Role | Permissions |
| --- | --- |
| **Owner** | Everything an editor can do, plus managing members, transferring ownership, and archiving and deleting the project. A project has exactly one owner. |
| **Editor** | Change the diagram, documentation, and facts; run imports and updates from code. |
| **Reader** | View the diagram and documentation; use search and export. |

Only users with the Architect account role can be owners or editors. A user with the Viewer account role can only be a reader in any project. ArchMap administrators are always architects, see all projects, and act as the owner in each of them.
