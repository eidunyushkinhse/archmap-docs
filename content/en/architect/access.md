::: note
A new project is visible only to its creator and to administrators. To let others work with the project, add them as members or make the project readable by all users. Only the project owner can change access.
:::

## Add a member

To add a member, follow these steps:

1. On the **Projects** screen, click **⋯** on the project card.
2. Select **Access**. The **Project access** window opens.
3. In the **Add member** field, enter the user's username. Suggestions appear as you type.
4. To the right of the field, select a role: **Editor** or **Reader**.
5. Click **Add**. The user appears in the **Members** list.

::: note
A user with the Viewer account role can only be given the **Reader** role. If you enter such a user's username, the **A Viewer can only be a reader** hint appears under the field.
:::

::: note
An editor can open the **Project access** window too, but only to view the list of members.
:::

## Change a member's role or remove a member {#member}

To change a member's role or remove them from the project, follow these steps:

1. Open the **Project access** window.
2. In the **Members** list, find the user and do one of the following:
    - select a new role in the list to the right of the name;
    - click **Remove**.

    The change is saved immediately.

## Make a project readable by everyone

To make the project visible to all users, follow these steps:

1. Open the **Project access** window.
2. Select **Visible to all users**. Users who aren't members of the project can view it but can't change it.

::: note
To hide the project again, clear the check box. Project members keep their roles.
:::

## Transfer ownership

To transfer the project to another architect, follow these steps:

1. Open the **Project access** window.
2. In the owner's row, click **Transfer ownership**. The **New owner** field appears under the list of members.
3. In the **New owner** field, select a user.
4. Click **Transfer**. A confirmation window opens.
5. Click **Transfer**.

::: note
After the transfer, you stay in the project as an editor. You can make any user with the Architect account role the owner, even if they aren't a project member yet.
:::
