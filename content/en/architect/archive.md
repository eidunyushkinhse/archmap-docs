---
title: Archive, restore, or delete a project
order: 18
---

::: note
You can move a project you no longer work on to the archive. It disappears from the list of active projects, but all its data is kept. You can restore an archived project or delete it permanently. Only the project owner can do this.
:::

## Archive a project {#archive}

To move a project to the archive, follow these steps:

1. On the **Projects** screen, on the **Active** tab, click **⋯** on the project card.
2. Select **Archive**. A confirmation window opens.
3. Click **Move to archive**. The project moves to the **Archive** tab.

## Restore a project from the archive

To restore a project from the archive, follow these steps:

1. On the **Projects** screen, open the **Archive** tab.
2. Click **⋯** on the project card.
3. Select **Restore**. A confirmation window opens.
4. Click **Restore**. The project appears on the **Active** tab again.

## Delete a project permanently

To delete a project permanently, follow these steps:

1. Move the project to the archive (see [Archive a project](#archive)).
2. On the **Projects** screen, open the **Archive** tab.
3. Click **⋯** on the project card.
4. Select **Delete permanently**. A confirmation window opens.
5. Enter the project name.
6. Click **Delete permanently**.

::: note
Deletion can't be undone. All the project's objects, relationships, documentation, and business processes are deleted along with it. If you may need the project later, download its archive before deleting it (see [Download the project archive](../user/export.md#download-the-project-archive)).
:::
