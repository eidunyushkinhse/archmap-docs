::: note
[Площадка](../glossary.md#site) в ArchMap описывает место, где работают объекты системы: облако, кластер Kubernetes, виртуальная машина, физический сервер или что-то другое. Площадки вложены друг в друга, например кластер лежит внутри облака. Объект стоит на одной площадке или на нескольких сразу, по экземпляру на каждой. Площадки и размещение описывает архитектор (см. [Разместить объекты по площадкам](../architect/deployment.md)).
:::

## Найти объект на схеме развёртывания

Чтобы найти объект на схеме развёртывания, выполните следующие действия:

1. Откройте проект и в шапке в переключателе режимов выберите **Развёртывание**. Откроется схема развёртывания всего проекта, слева дерево объектов.
2. Найдите объект одним из способов:
    - в дереве слева нажмите на объект;
    - в поле **Поиск по имени** над деревом введите часть имени и нажмите на найденный объект. Поиск находит и компоненты, которых в этом дереве нет.

    На схеме выделится объект на каждой площадке, где он стоит. У компонента выделится его контейнер.
3. Если на схеме тесно, сверните лишние площадки. Для этого нажмите на подпись площадки. Чтобы раскрыть свёрнутую площадку, дважды нажмите на неё.

![Схема развёртывания](../images/deploy-canvas.png "Схема развёртывания маркетплейса «Ярмарка»: площадки показаны зонами, объекты стоят на них карточками")

::: note
Объект на нескольких площадках показан на каждой из них с пометкой вида **1/2**. Остальные обозначения расшифровывает кнопка **Легенда** в углу схемы.
:::

::: note
Если в дереве нажать на систему, на схеме останутся только её объекты. Ко всему проекту ведёт ссылка **Весь проект** над схемой.
:::

::: note
Связи на схеме развёртывания можно разобрать так же, как на схеме объектов (см. [Просмотреть связи на схеме](edges.md#просмотреть-связи-на-схеме)).
:::

## Узнать площадки объекта на его странице

Чтобы узнать площадки объекта на его странице, выполните следующие действия:

1. Откройте страницу объекта (см. [Перемещаться по уровням схемы](levels.md)).
2. В разделе **Свойства** найдите строку **Размещение**. В ней перечислены площадки, где стоит объект.
