::: note
Агент отвечает по документации проекта в ArchMap. Он ищет по всему её содержимому (объектам, схемам логики, спецификациям API, таблицам, каналам, параметрам конфигурации и бизнес-процессам) и читает найденное. В интерфейсе ArchMap поиск есть только по имени объекта, поэтому вопросы по содержимому удобнее задавать агенту.
:::

## Задать вопрос

Чтобы задать вопрос о системе, выполните следующие действия:

1. Запустите агента, подключённого к ArchMap (см. [Подключить ИИ-агента к ArchMap](agent-setup.md)).
2. Сформулируйте вопрос и назовите в нём проект. Если не помните название проекта, сначала попросите агента показать список проектов.
3. Отправьте вопрос. Агент найдёт нужное в документации и ответит, указав, где это записано: путь объекта, название схемы логики, номер строки в ней.
4. Проверьте важные выводы в ArchMap. Для этого откройте страницу названного объекта и нужную схему (см. [Найти документацию сервиса](find-service.md), [Просмотреть логику операции или воркера](logic.md)).

::: note
Примеры вопросов:
- «Какие сервисы пишут в orders.status в проекте „Маркетплейс «Ярмарка»“?»
- «Что происходит при оплате заказа в проекте „Ярмарка“? Опиши по шагам бизнес-процесса.»
- «От каких параметров конфигурации зависит Order API и что они переключают?»
- «Где в проекте „Ярмарка“ возникает ошибка „…“ и что сервис делает после неё?»
:::

::: note
Строку из лога вставляйте в вопрос целиком. Переменные части (идентификаторы, пути, даты) поиску не мешают, а редкие слова помогают найти нужное место.
:::

::: note
Отвечает агент, а не ArchMap: агент может ошибиться в выводах. Документация в ArchMap описывает систему так, как её задокументировали, поэтому то, чего в ней нет, агент не узнает.
:::
