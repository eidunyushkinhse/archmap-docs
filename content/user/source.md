::: note
Источник объекта показывает, где лежит его код: репозиторий и путь в нём. У зависимости без кода в продукте (базы данных, брокера, соседнего продукта) источник указывает имя, под которым продукт называет её в своих настройках. По источнику ArchMap узнаёт объект, когда документация обновляется из кода.
:::

## Найти код сервиса

Чтобы найти репозиторий и путь к коду сервиса, выполните следующие действия:

1. Откройте страницу сервиса (см. [Найти документацию сервиса](find-service.md)).
2. Под описанием сервиса найдите строку **Источник**. В ней указано одно из следующего:
    - репозиторий и через косую черту путь к каталогу сервиса (если пути нет, сервису соответствует весь репозиторий);
    - имя, под которым продукт называет объект в своих настройках (например, в docker-compose). Кода этого объекта в продукте нет.
3. Скопируйте адрес репозитория и откройте его в браузере.
4. В репозитории перейдите в каталог, указанный после косой черты.

![Строка Источник](../images/source-props.png "Источник сервиса Order API: репозиторий github.com/yarmarka/orders, путь services/order-api")

::: note
Если строки **Источник** нет, источник у объекта не указан. У объектов, которые ИИ-агент описал по коду, источник заполняется автоматически, а у добавленных вручную его может не быть.
:::

::: note
Источник описывает продукт, а не развёртывание: адресов серверов и сред в нём нет.
:::
