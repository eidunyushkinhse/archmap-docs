::: note
Проект в ArchMap устроен как дерево объектов. Объект, у которого есть компоненты, называется контейнером. Контейнером может быть только сервис; у базы данных, брокера и пользователя компонентов не бывает. Уровень состоит из компонентов одного контейнера и связей между ними. Корневой уровень показан на странице проекта, остальные уровни открываются со страниц объектов.
:::

## Открыть страницу объекта

Чтобы открыть страницу объекта, выполните одно из следующих действий:

- дважды нажмите на объект на схеме страницы проекта или другого объекта;
- нажмите на объект в дереве слева;
- введите часть имени в поле **Поиск по имени…** над деревом и нажмите на найденный объект.

![Страница объекта](../images/object-page.png "Страница объекта Сервис заказов: путь от корня проекта, свойства и схема объекта с соседями")

::: note
На схеме страницы объекта показаны:
- сам объект;
- соседи с того же уровня, с которыми он связан (сплошной рамкой);
- соседи с других уровней (пунктирной рамкой);
- связи между всеми ними, включая связи соседей друг с другом;
- пунктирная рамка родительского контейнера.

Объекты того же уровня, с которыми объект не связан, на его схему не попадают: их видно на схеме родителя.
:::

::: note
Ниже схемы на странице объекта расположены разделы **Связи**, **Логика**, **OpenAPI** и **Участвует в процессах** (см. [Просмотреть связи сервиса](edges.md), [Просмотреть логику операции или воркера](logic.md), [Просмотреть API сервиса](api.md), [Просмотреть бизнес-процесс](processes.md)).
:::

## Спуститься на уровень ниже

Чтобы просмотреть компоненты контейнера, не покидая схему, выполните следующие действия:

1. Найдите контейнер на схеме: у него есть лупа **Раскрыть содержимое**.
2. Нажмите лупу. Внутри рамки контейнера появятся его компоненты, стрелки протянутся к ним.
3. Спуститесь ещё глубже. Для этого нажмите лупу на любом компоненте-контейнере.
4. Скройте компоненты. Для этого нажмите **Свернуть** в углу рамки.

![Контейнер раскрыт на схеме](../images/object-page-expanded.png "Контейнер раскрыт лупой: его компоненты видны внутри рамки вместе с соседями")

::: note
Так можно раскрыть контейнер и на странице проекта, и на странице любого объекта.
:::

::: note
Подряд можно раскрыть только два уровня: глубже лупа становится неактивной и подсказывает спуститься на страницу компонента.
:::

Чтобы перейти на уровень компонента, выполните следующие действия:

1. Раскройте контейнер лупой **Раскрыть содержимое**.
2. Дважды нажмите на компонент. Откроется его страница со схемой его уровня.

## Вернуться на уровень выше

Чтобы вернуться на уровень выше, выполните одно из следующих действий:

- нажмите на имя предка в пути **Проект › …** вверху страницы объекта;
- вернитесь к корневому уровню на странице проекта. Для этого нажмите **Проект** в начале того же пути;
- нажмите на предка в дереве слева.

## Пользоваться деревом объектов

Чтобы найти объект в дереве слева, выполните следующие действия:

1. Нажмите на стрелку слева от имени контейнера. Ветка раскроется.
2. Нажмите на имя объекта. Откроется его страница.

::: note
Дерево само раскрывается до объекта, страница которого открыта. Кнопка **Свернуть панель** внизу прячет дерево, **Развернуть панель** возвращает его.
:::

::: note
Поле **Поиск по имени…** над деревом ищет только по именам объектов. Поиск по всей документации проекта описан в разделе [Найти документацию сервиса](find-service.md).
:::
