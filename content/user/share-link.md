---
title: Поделиться ссылкой на уровень или объект
order: 13
---

::: note
У каждой страницы проекта и объекта постоянный адрес: по нему откроется та же страница. Корневой уровень схемы показан на странице проекта, остальные уровни на страницах объектов (см. [Перемещаться по уровням схемы](levels.md)).
:::

## Скопировать ссылку

Чтобы поделиться ссылкой, выполните следующие действия:

1. Откройте нужную страницу:
    - страницу проекта, чтобы показать корневой уровень схемы;
    - страницу объекта, чтобы показать объект на его уровне вместе с документацией.
2. Скопируйте адрес из адресной строки браузера.
3. Отправьте адрес получателю.

::: note
Получатель увидит страницу, только если у него есть доступ к проекту: он участник проекта или проект открыт всем пользователям. Иначе вместо страницы появится сообщение **Не найдено — возможно, объект удалили или ссылка устарела**.
:::

::: note
Если получатель не вошёл в ArchMap, сначала откроется страница входа, а после входа нужная страница.
:::

::: note
На бизнес-процесс отдельной ссылки нет. Отправьте ссылку на проект и назовите процесс. Получатель откроет его кнопкой **Процессы** (см. [Просмотреть бизнес-процесс](processes.md)).
:::

::: note
Вид схемы (**Как есть**, **Переход**, **Как будет**) в ссылку не попадает: у получателя схема откроется в том виде, который выбран у него.
:::
