::: note
ИИ-агент (Claude Code, Claude Desktop или другой агент с поддержкой MCP) работает с ArchMap через MCP-сервер. Сервер запускается на вашем компьютере рядом с агентом и обращается к ArchMap от имени вашей учётной записи. Для установки нужны git и Python 3.11 или новее.
:::

## Установить MCP-сервер

Чтобы установить MCP-сервер, выполните следующие действия:

1. Скачайте репозиторий ArchMap:

    ```bash
    git clone https://github.com/eidunyushkinhse/archmap.git
    ```

2. Перейдите в папку `archmap/mcp` и установите зависимости сервера:

    ```bash
    cd archmap/mcp
    python3 -m venv venv
    ./venv/bin/pip install -r requirements.txt
    ```

::: note
В Windows виртуальное окружение создаётся командой `python -m venv venv`, а зависимости ставятся командой `venv\Scripts\pip install -r requirements.txt`.
:::

## Указать учётную запись

Чтобы указать учётную запись, выполните следующие действия:

1. В папке `mcp` скопируйте файл `.env.example` в файл `.env`.
2. В файле `.env` заполните параметры:
    - `ARCHMAP_URL`: адрес, по которому ArchMap открывается в браузере, без пути (например, `https://archmap.example.com`);
    - `ARCHMAP_USERNAME` и `ARCHMAP_PASSWORD`: ваши логин и пароль ArchMap.

::: note
Файл `.env` не попадает в git. Пароль в конфигурацию агента не пишите: её файл может оказаться в репозитории.
:::

## Подключить сервер к агенту

Чтобы подключить MCP-сервер к агенту, выполните следующие действия:

1. Откройте файл конфигурации MCP-серверов агента:
    - у Claude Code это файл `.mcp.json` в папке, из которой вы запускаете агента;
    - у Claude Desktop это файл `claude_desktop_config.json`.
2. Добавьте в файл сервер `archmap`. Вместо `/путь/к/archmap/mcp` укажите полный путь к папке `mcp`:

    ```json
    {
      "mcpServers": {
        "archmap": {
          "command": "/путь/к/archmap/mcp/venv/bin/python",
          "args": ["-m", "archmap_mcp.server"],
          "env": {
            "PYTHONPATH": "/путь/к/archmap/mcp"
          }
        }
      }
    }
    ```

3. Перезапустите агента. Если агент спросит разрешение запустить сервер `archmap`, разрешите.
4. Проверьте подключение. Для этого попросите агента показать список проектов ArchMap. Агент ответит списком проектов, доступных вашей учётной записи, и вашей ролью в каждом.

::: note
В Windows в параметре `command` укажите путь к `venv\Scripts\python.exe`.
:::

::: note
Если ArchMap открывается по HTTPS с сертификатом внутреннего центра сертификации, добавьте в блок `env` параметр `SSL_CERT_FILE` с путём к файлу корневых сертификатов (например, `/etc/ssl/certs/ca-certificates.crt`). Если доступ в сеть идёт через прокси, внесите адрес ArchMap в параметр `NO_PROXY` того же блока.
:::

::: note
Агент видит в ArchMap то же, что ваша учётная запись. С ролью читателя агент ничего не меняет в проекте: на попытку правки ArchMap ответит отказом **Недостаточно прав**.
:::

::: note
К демонстрационному стенду агента подключить нельзя: вход по логину и паролю там закрыт.
:::
