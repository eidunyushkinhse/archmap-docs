::: note
[Конфигурацию](glossary.md#config) читает контейнер целиком, поэтому параметры описаны на странице [контейнера](glossary.md#container). На странице компонента раздел **Конфигурация** ведёт к его контейнеру.
:::

::: note
Параметры конфигурации связаны со схемами логики через пометки «зависит от» в шагах схем (см. [Просмотреть логику операции или воркера](logic.md)). По этим пометкам раздел **Конфигурация** показывает, от каких параметров зависят схемы контейнера и его компонентов.
:::

## Просмотреть параметр

Чтобы просмотреть конфигурацию сервиса, выполните следующие действия:

1. Откройте страницу контейнера (см. [Найти документацию сервиса](find-service.md)) и прокрутите до раздела **Конфигурация**.
2. В разделе **Конфигурация** найдите нужный параметр.
3. Под параметром в строке **зависит:** прочитайте названия схем логики, шаги которых зависят от параметра. Схема компонента названа вместе с именем компонента.

![Раздел Конфигурация](../images/facts-config.png "Раздел Конфигурация сервиса Order API: параметры и схемы, которые от них зависят")

::: note
В столбце **По умолчанию** указано значение из кода сервиса. Значения параметров в средах (тестовой, рабочей и других) ArchMap не хранит.
:::

::: note
Строка **зависит:** есть только у параметров, на которые ссылаются пометки «зависит от» в схемах логики контейнера и его компонентов. Названия схем в этой строке не открываются. Открыть схему можно в разделе **Логика** на той же странице (см. [Просмотреть логику операции или воркера](logic.md)).
:::

::: note
Если в разделе написано **Параметры не описаны**, конфигурация контейнера в проекте пока не задокументирована.
:::
