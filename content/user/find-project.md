::: note
Проект в ArchMap — это одна система: её объекты, связи между ними, документация и бизнес-процессы. Проект показывается всем его участникам, а если владелец открыл его всем пользователям — каждому, кто вошёл в сервис. Проект, в который вас не добавили, в списке не появится и по прямой ссылке не откроется. Участников добавляет владелец проекта (см. [Открыть проект участникам и назначить роли](../architect/access.md)).
:::

## Найти проект

Чтобы найти проект, выполните следующие действия:

1. Войдите в ArchMap. Откроется экран **Проекты** со списком проектов, доступных вам.
2. Если проектов много, введите часть названия или описания в поле **Поиск по имени или описанию**. Список сузится по мере ввода.
3. Нажмите на карточку проекта. Откроется страница проекта.

![Экран Проекты](../images/projects-list.png "Экран Проекты: вкладки Активные и Архив, поиск и карточки проектов")

::: note
На карточке проекта показаны:
- миниатюра схемы корневого уровня;
- название и описание;
- кто и когда менял проект последним;
- число объектов и связей.
:::

::: note
Вкладка **Архив** показывает проекты, отправленные в архив. Архивный проект не открывается, пока владелец его не восстановит.
:::

::: note
Если вы перешли по ссылке на страницу внутри проекта, после входа откроется она. К списку проектов в любой момент ведёт логотип **ArchMap** в левом верхнем углу.
:::

Чтобы перейти в другой проект, не возвращаясь к списку, выполните следующие действия:

1. Нажмите на название проекта в шапке. Раскроется список проектов.
2. Выберите проект одним из способов:
    - нажмите на него в списке;
    - введите часть названия в поле **Поиск проекта** и нажмите на найденный проект.

::: note
Пункт **Все проекты** в том же списке ведёт на экран **Проекты**.
:::

## Просмотреть устройство системы

Чтобы просмотреть устройство системы, выполните следующие действия:

1. Откройте страницу проекта. На ней:
    - в шапке — название, описание и три счётчика: сколько в проекте объектов, связей и бизнес-процессов;
    - слева — дерево объектов проекта;
    - справа — карточка **Схема системы** с корневым уровнем: системами верхнего уровня и связями между ними.
2. Нажмите на схему. Подсказка **кликните, чтобы взаимодействовать** исчезнет, схема включится.
3. Подберите масштаб и положение схемы одним из способов:
    - колесом измените масштаб;
    - перетащите схему за пустое место;
    - нажмите кнопки в левом нижнем углу схемы: приблизить, отдалить, вписать схему в окно.
4. Нажмите на объект. Объект выделится, все его связи подсветятся.
5. Нажмите лупу **Раскрыть содержимое** на объекте-контейнере. Внутри его рамки появятся компоненты контейнера, связи протянутся к ним. Кнопка **Свернуть** в углу рамки скрывает их.
6. Дважды нажмите на стрелку. Связь подсветится по всей длине. Если по одной линии идёт несколько связей, ArchMap предложит выбрать нужную.
7. Нажмите <kbd>Esc</kbd> или кликните вне схемы. Схема снова станет неподвижной.

![Страница проекта](../images/project-home.png "Страница проекта: шапка со счётчиками, дерево объектов слева и карточка Схема системы")

::: note
Пока схема не включена, она не реагирует на колесо и перетаскивание — чтобы страница не перехватывала прокрутку.
:::

::: note
Кнопка **Легенда** в правом нижнем углу схемы открывает справочник обозначений:
- формы объектов: сервис, база данных, брокер сообщений, пользователь;
- цвета статусов: существует, проектируется, выводится;
- пунктирная рамка объекта с другого уровня;
- граница родительского слоя.

Кнопка в правом верхнем углу схемы скрывает и возвращает подписи связей.
:::

::: note
Если в проекте описаны планируемые изменения, над схемой появляется переключатель **Как есть** / **Переход** / **Как будет** (см. [Просмотреть планируемые изменения системы](changes.md)).
:::

::: note
Пока вы читаете, проект могут править другие участники. Схема на странице обновляется сама, над ней на несколько секунд появляется подпись **Схема обновлена в другой сессии**.
:::

Чтобы просмотреть список бизнес-процессов системы, выполните следующие действия:

1. Прокрутите страницу проекта до карточки **Бизнес-процессы**. В ней — название каждого процесса и число сообщений в нём.
2. Нажмите на строку процесса. Проект переключится в режим **Процессы**, откроется выбранный процесс (см. [Просмотреть бизнес-процесс](processes.md)).

::: note
Карточки **Бизнес-процессы** нет, если процессов в проекте ещё не описали.
:::

## Перейти на первый уровень

Чтобы перейти с корневой схемы на уровень объекта, выполните следующие действия:

1. Откройте страницу объекта одним из способов:
    - дважды нажмите на объект на схеме;
    - нажмите на объект в дереве слева.
2. На странице объекта найдите схему его уровня. Дальше перемещайтесь по уровням, как описано в разделе [Перемещаться по уровням схемы](levels.md).

::: note
Чтобы найти конкретный сервис, не спускаясь по уровням, воспользуйтесь поиском (см. [Найти документацию сервиса](find-service.md)).
:::
