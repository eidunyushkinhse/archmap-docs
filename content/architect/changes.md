::: note
Статус объекта показывает его место в плане изменений: **Существует** (работает сейчас), **Проектируется** (появится) или **Выводится** (будет выведен из эксплуатации). По статусам читатель видит систему такой, как она есть, какой станет и переход между ними (см. [Просмотреть планируемые изменения системы](../user/changes.md)).
:::

## Отметить планируемые изменения

Чтобы отметить изменения, выполните следующие действия:

1. Добавьте объекты, которые появятся в системе, и связи к ним (см. [Добавить объекты и контейнеры](nodes.md)).
2. Откройте страницу нового объекта.
3. В разделе **Свойства** в строке **Статус** выберите **Проектируется**.
4. Откройте страницу объекта, который будет выведен из эксплуатации, и в строке **Статус** выберите **Выводится**.

::: note
Статус можно выбрать и в редакторе схемы: в панели свойств объекта справа.
:::

::: note
Связи нового объекта на схеме зелёные, связи выводимого — красные. Отдельного статуса у связи нет: её цвет следует за статусом объектов на концах.
:::

## Проверить план

Чтобы проверить, как будет выглядеть система после изменений, выполните следующие действия:

1. Откройте страницу проекта или объекта.
2. Над схемой выберите вид **Как будет**. Выводимые объекты станут бледными.
3. Проверьте, что без выводимых объектов схема остаётся связной: новые объекты взяли на себя их связи.
4. Выберите вид **Как есть** и проверьте, что запланированные объекты не нужны текущей системе.

::: note
Переключатель **Как есть** / **Переход** / **Как будет** появляется, только если в проекте есть объекты со статусом **Проектируется** или **Выводится**.
:::

## Принять переход после внедрения

::: note
Когда изменения внедрены, план нужно превратить в факт: новые объекты становятся существующими, а выведенные удаляются со схемы.
:::

Чтобы принять переход, выполните следующие действия:

1. Откройте редактор схемы (см. [Добавить объекты и контейнеры](nodes.md#editor)).
2. В шапке редактора рядом с переключателем вида нажмите **Принять переход**. Откроется окно со списком изменений.
3. Проверьте списки:
    - **Станут существующими**: объекты со статусом **Проектируется**;
    - **Будут удалены**: объекты со статусом **Выводится**;
    - **Уедут заодно**: компоненты удаляемых объектов, которые выводимыми не отмечены.
4. Нажмите **Принять переход**.

::: note
Принятие перехода нельзя отменить: удалённые объекты пропадают вместе с компонентами, связями, схемами логики и спецификациями. Переход принимается для всего проекта сразу, а не для одного уровня.
:::

::: note
Перед принятием перехода сделайте копию проекта или выгрузите архив, если старая схема может понадобиться (см. [Экспортировать и импортировать проект](export-import.md)).
:::
