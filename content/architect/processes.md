::: note
Бизнес-процесс собирается из уже описанной архитектуры: участниками процесса становятся объекты схемы, а сообщение между ними можно провести только по связи, которая есть на схеме. Поэтому процесс и схема не расходятся: если связи нет, её сначала нужно добавить в схему (это можно сделать прямо из процесса). Как процесс выглядит у читателя, описано в [Просмотреть бизнес-процесс](../user/processes.md).
:::

## Создать процесс

Чтобы создать процесс, выполните следующие действия:

1. Откройте проект и в правом верхнем углу нажмите **Процессы**. Слева откроется список процессов.
2. Над списком нажмите **Новый процесс**. Появится пустой процесс, открытый в режиме правки.
3. На панели над диаграммой нажмите **Участник**. Откроется дерево объектов схемы.
4. Отметьте объекты, которые участвуют в процессе, и нажмите **Добавить**. Над диаграммой появятся участники.
5. Добавьте сообщения (см. [Добавить сообщение](#message)).
6. На панели над диаграммой нажмите **Готово**.

::: note
Новый процесс называется «Новый процесс». Задать своё название можно, если создать процесс импортом из Mermaid (см. [Импортировать процесс из Mermaid](#import)).
:::

::: note
Порядок участников можно изменить, перетащив их шапки влево или вправо. Крестик в углу шапки убирает участника вместе с его сообщениями.
:::

## Добавить сообщение {#message}

Чтобы добавить сообщение, выполните следующие действия:

1. Откройте процесс и на панели над диаграммой нажмите **Редактировать**.
2. Под линией участника, который отправляет сообщение, нажмите на кружок и протяните стрелку к участнику-получателю. Откроется окно **Добавить сообщение** со связями между ними.
3. Выберите, что передаётся:
    - **вызов**: запрос по синхронной связи;
    - **ответ**: ответ на вызов по той же связи;
    - **событие**: сообщение по асинхронной связи (например, через брокер).
4. Нажмите **Добавить сообщение**. Шаг появится внизу диаграммы с подписью связи.

::: note
Если между участниками нет связи, окно предупредит об этом и предложит описать её: заполните поля **Что передаётся**, **Технология**, выберите **Тип канала** и нажмите **Добавить связь в схему**. Связь появится и на схеме, и в окне как вариант сообщения.
:::

::: note
Тип канала (синхронный или асинхронный) задаётся у связи и общий для всех шагов процессов, которые идут по этой связи. У асинхронной связи нет ответа.
:::

::: note
Действие участника над самим собой (например, проверка заказа) проводится стрелкой из кружка участника обратно к нему же. Такому шагу связь на схеме не нужна.
:::

## Настроить шаг

Чтобы изменить подпись шага или привязать к нему схему логики, выполните следующие действия:

1. В режиме правки нажмите на стрелку или подпись шага. Откроется панель **Шаг сценария**.
2. Если нужно, измените подпись шага.
3. В поле **Схема логики** нажмите **Выбрать** и найдите схему логики операции, которая выполняет шаг. Поиск работает по имени схемы, операции и объекту.
4. Нажмите **Сохранить**.

::: note
Привязанная схема открывается у читателя кликом по подписи шага. Шаги без схемы логики попадают в **Рекомендации**.
:::

::: note
Порядок шагов можно изменить, перетащив шаг вверх или вниз. Удалить шаг можно кнопкой **Удалить** на панели **Шаг сценария**.
:::

## Выделить ветки, повторы и параллельные шаги

Чтобы сгруппировать шаги во фрагмент, выполните следующие действия:

1. В режиме правки на панели над диаграммой рядом с надписью **Фрагмент:** выберите вид:
    - **alt**: выполняется одна из веток;
    - **opt**: шаги выполняются только при условии;
    - **loop**: шаги повторяются;
    - **par**: шаги выполняются параллельно.
2. Протяните курсором по строкам шагов, которые входят во фрагмент.
3. На панели фрагмента введите условие (например, «оплата прошла») и нажмите **Добавить**.
4. Для фрагмента **alt** добавьте следующую ветку. Для этого в шапке фрагмента нажмите **+ иначе**, введите условие ветки и нажмите **Добавить**. Граница ветки встанет в свободном месте фрагмента: перетащите её на шаг, с которого начинается ветка.

::: note
Границы фрагмента можно перетащить, чтобы включить в него больше или меньше шагов. Фрагменты можно вкладывать друг в друга. Удалить фрагмент можно нажатием на его шапку.
:::

## Импортировать процесс из Mermaid {#import}

Чтобы импортировать процесс, выполните следующие действия:

1. В режиме **Процессы** над списком процессов нажмите **Импорт из Mermaid**. Откроется окно импорта.
2. В поле **Текст диаграммы** вставьте sequence-диаграмму Mermaid.
3. Нажмите **Разобрать**. Появится список участников диаграммы.
4. В поле **Название процесса** введите название.
5. Для каждого участника проверьте, с каким объектом схемы он сопоставился, и при необходимости выберите объект.
6. Нажмите **Импортировать**. Откроется новый процесс.

::: note
Если участника не сопоставить с объектом, он останется в процессе без объекта схемы, а если для шага не нашлось однозначной связи, шаг станет повисшим. Такие участники и шаги видны в **Рекомендациях**. Привязать участника к объекту можно кнопкой на его шапке. Подобрать связи повисшим шагам можно кнопкой **Восстановить связи** на панели над диаграммой.
:::

::: note
Процесс можно и выгрузить обратно в Mermaid (см. [Экспортировать проект](../user/export.md#выгрузить-бизнес-процесс-в-mermaid)).
:::

## Дублировать или удалить процесс

Чтобы дублировать или удалить процесс, выполните следующие действия:

1. В списке процессов наведите курсор на процесс и нажмите кнопку **···**.
2. Выберите **Дублировать** или **Удалить**.

::: note
Все правки процесса можно отменить кнопками отмены на панели над диаграммой или клавишами <kbd>Ctrl</kbd>+<kbd>Z</kbd> и <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>.
:::
