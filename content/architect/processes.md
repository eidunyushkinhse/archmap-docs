::: note
Бизнес-процесс собирается из уже описанной архитектуры: участниками процесса становятся объекты схемы, а сообщение между ними можно провести только по связи, которая есть на схеме. Поэтому процесс и схема не расходятся: если связи нет, её сначала нужно добавить в схему (это можно сделать прямо из процесса). Как процесс выглядит у читателя, описано в [Просмотреть бизнес-процесс](../user/processes.md).
:::

## Создать процесс

Чтобы создать процесс, выполните следующие действия:

1. Откройте проект и в шапке нажмите **Процессы**. Слева откроется список процессов.
2. Над списком нажмите **Добавить** и выберите **Новый процесс**.
3. Введите название процесса и нажмите <kbd>Enter</kbd>. Процесс откроется в режиме правки.
4. Над диаграммой нажмите **Добавить участника**. Откроется окно **Участники**.
5. Отметьте объекты, которые участвуют в процессе, и нажмите **Добавить**. Над диаграммой появятся участники.
6. Закройте окно **Участники**.
7. Добавьте шаги (см. [Добавить шаг](#message)).
8. Над диаграммой нажмите **Готово**.

::: note
Порядок участников можно изменить, перетащив их шапки влево или вправо. Крестик на шапке убирает участника из процесса вместе с его шагами.
:::

## Добавить шаг {#message}

Чтобы добавить шаг, выполните следующие действия:

1. Откройте процесс и над диаграммой нажмите **Редактировать**.
2. Под линией участника, который отправляет сообщение, нажмите на кружок и протяните стрелку к участнику-получателю. Откроется окно **Добавить шаг** со связями между ними.
3. Выберите, что передаётся:
    - **вызов**: запрос по синхронной связи;
    - **ответ**: ответ на вызов по той же связи;
    - **событие**: сообщение по асинхронной связи (например, через брокер).
4. Нажмите **Добавить шаг**. Шаг появится внизу диаграммы с подписью связи.

::: note
Если между участниками нет связи, её можно описать прямо в окне кнопкой **Добавить связь в схему**. Связь появится и на схеме, и в окне как вариант шага.
:::

::: note
Тип связи (синхронный или асинхронный) задаётся у связи на схеме и общий для всех шагов процессов, которые идут по ней. У асинхронной связи нет ответа.
:::

::: note
Действие участника над самим собой (например, проверка заказа) связи на схеме не требует. Чтобы описать его, протяните стрелку из кружка вниз на кружок **Шаг внутри участника**, введите подпись и нажмите **Добавить**.
:::

## Настроить шаг

Чтобы изменить шаг или привязать к нему схему логики, выполните следующие действия:

1. В режиме правки нажмите на подпись шага. Справа откроются свойства шага.
2. Измените нужное:
    - подпись шага в поле над свойствами;
    - тип связи в строке **Тип**;
    - схему логики в строке **Схема логики**. Для этого нажмите **Выбрать** и в списке нажмите на схему логики операции, которая выполняет шаг.

::: note
Правки шага сохраняются сразу. Удалить шаг можно кнопкой **Удалить шаг** в его свойствах, а изменить порядок шагов можно, перетащив шаг вверх или вниз.
:::

::: note
Привязанная схема открывается у читателя значком после подписи шага. О шагах без схемы логики ArchMap напомнит в списке рекомендаций.
:::

## Выделить ветки, повторы и параллельные шаги

Чтобы сгруппировать шаги во фрагмент, выполните следующие действия:

1. В режиме правки над диаграммой нажмите **Фрагмент** и выберите вид фрагмента (например, **Цикл (loop)**).
2. Протяните курсором по строкам шагов, которые входят во фрагмент. Откроется окно фрагмента.
3. Введите условие (например, «оплата прошла») и нажмите **Добавить**.
4. Для фрагмента **Условие (alt)** добавьте следующую ветку. Для этого в шапке фрагмента нажмите **+ иначе**, введите условие ветки и нажмите **Добавить**. Граница ветки встанет в свободном месте фрагмента. Перетащите её на шаг, с которого начинается ветка.

::: note
Границы фрагмента можно перетащить, чтобы включить в него больше или меньше шагов. Фрагменты можно вкладывать друг в друга. Удалить фрагмент можно нажатием на его шапку.
:::

## Импортировать процесс из Mermaid {#import}

Чтобы импортировать процессы, выполните следующие действия:

1. На вкладке **Процессы** над списком процессов нажмите **Добавить** и выберите **Импорт из Mermaid**. Откроется окно **Импорт процессов**.
2. Добавьте диаграммы одним из способов:
    - в поле **Название процесса** введите название, а ниже вставьте sequence-диаграмму Mermaid;
    - нажмите **Выбрать файлы** и выберите файлы `.mmd`, `.md` или `.txt`. Каждый блок диаграммы в файле станет отдельным процессом.
3. Если в окне есть участники без объекта схемы, выберите для каждого объект.
4. Нажмите **Импортировать** (для нескольких процессов кнопка называется **Импортировать N процессов**). Процессы появятся в списке слева.

::: note
Участник без объекта схемы и шаг без однозначной связи останутся в процессе, и ArchMap покажет их в списке рекомендаций (см. [Разобрать рекомендации к схеме](alerts.md)).
:::

::: note
Процесс можно и выгрузить обратно в Mermaid (см. [Экспортировать проект](../user/export.md#выгрузить-бизнес-процесс-в-mermaid)).
:::

## Заменить процесс из Mermaid {#replace}

Чтобы заменить шаги процесса новой диаграммой, выполните следующие действия:

1. В списке процессов наведите курсор на процесс, нажмите **Действия** (три точки) и выберите **Заменить из Mermaid**. Откроется окно **Заменить процесс**.
2. Вставьте текст диаграммы или нажмите **Выбрать файл** и выберите файл.
3. Если в окне есть участники без объекта схемы, выберите для каждого объект.
4. Нажмите **Заменить**. Шаги процесса сменятся на новые.

::: note
Перед заменой ArchMap сохраняет версию проекта с комментарием «Перед заменой процесса «…» из диаграммы», и прежний вариант процесса остаётся в ней.
:::

Чтобы вернуть прежний вариант процесса, выполните следующие действия:

1. На странице проекта откройте окно **Версии** (см. [Зафиксировать версию документации и вернуться к ней](versions.md)) и нажмите на версию, сохранённую перед заменой.
2. Рядом с заголовком **Что изменилось** выберите **с текущим состоянием** и нажмите на процесс.
3. На вкладке **Было в vN** нажмите **Скопировать**. В буфере окажется текст диаграммы прежнего варианта.
4. Замените процесс этим текстом, как описано выше.

## Переименовать процесс {#rename}

Чтобы переименовать процесс, выполните следующие действия:

1. В списке процессов слева дважды нажмите на имя процесса. Вместо имени появится поле ввода.
2. Введите новое имя.
3. Нажмите <kbd>Enter</kbd>.

::: note
Новое имя сохранится и тогда, когда вы нажмёте в любом другом месте экрана. Чтобы отказаться от переименования, нажмите <kbd>Esc</kbd>.
:::

## Дублировать или удалить процесс

Чтобы дублировать или удалить процесс, выполните следующие действия:

1. В списке процессов наведите курсор на процесс и нажмите **Действия** (три точки).
2. Выберите **Дублировать** или **Удалить**. Удаление подтвердите повторным нажатием.

::: note
Все правки процесса можно отменить кнопками отмены над диаграммой или клавишами <kbd>Ctrl</kbd>+<kbd>Z</kbd> и <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>.
:::
