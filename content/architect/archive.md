::: note
Проект, с которым больше не работают, можно убрать в архив: он пропадёт из списка активных, но все данные сохранятся. Из архива проект можно вернуть или удалить навсегда. Это может только владелец проекта.
:::

## Отправить проект в архив

Чтобы отправить проект в архив, выполните следующие действия:

1. На экране **Проекты** на вкладке **Активные** на карточке проекта нажмите кнопку **⋯**.
2. В меню выберите пункт **Архивировать**. Откроется окно подтверждения.
3. Нажмите кнопку **В архив**. Проект переместится на вкладку **Архив**.

## Восстановить проект из архива

Чтобы вернуть проект из архива, выполните следующие действия:

1. На экране **Проекты** откройте вкладку **Архив**.
2. На карточке проекта нажмите кнопку **⋯**.
3. В меню выберите пункт **Восстановить**. Откроется окно подтверждения.
4. Нажмите кнопку **Вернуть**. Проект снова появится на вкладке **Активные**.

## Удалить проект навсегда

Чтобы удалить проект навсегда, выполните следующие действия:

1. Отправьте проект в архив (см. [Отправить проект в архив](#отправить-проект-в-архив)).
2. На экране **Проекты** откройте вкладку **Архив**.
3. На карточке проекта нажмите кнопку **⋯**.
4. В меню выберите пункт **Удалить навсегда**. Откроется окно подтверждения.
5. Введите имя проекта.
6. Нажмите кнопку **Удалить навсегда**.

::: note
Удаление нельзя отменить: вместе с проектом пропадут все объекты, связи, документация и бизнес-процессы. Если проект может понадобиться, перед удалением скачайте его архив (см. [Скачать архив проекта](../user/export.md#скачать-архив-проекта)).
:::
