---
title: Собрать схему и факты из репозитория без агента

---

::: note
Сборщик фактов ArchMap — один файл, который вы запускаете в репозитории системы. Он читает манифесты развёртывания и сборки, миграции и код и собирает скелет схемы (контейнеры, базы данных, брокеры и связи между ними), структуру таблиц, параметры конфигурации и каналы брокеров. Результат импортируется в ArchMap теми же окнами, что и файлы от ИИ-агента, а сам агент для этого не нужен.
:::

## Скачать сборщик фактов

Чтобы скачать сборщик фактов, выполните следующие действия:

1. На экране **Проекты** нажмите кнопку **Новый проект**. Откроется окно **Новый проект**.
2. В окне **Новый проект** выберите способ **Импорт**. Слева под способами появится строка о сборщике фактов.
3. В этой строке нажмите ссылку **сборщик фактов**. Браузер скачает файл `archmap-scan.pyz`.

::: note
Файл можно скачать и без входа в ArchMap по адресу `<адрес ArchMap>/api/v1/scan/archmap-scan.pyz` (например, командой `curl -sSfL -o archmap-scan.pyz https://archmap.example.com/api/v1/scan/archmap-scan.pyz`). Та же ссылка есть в окне **Обновить из кода**.
:::

::: note
Для запуска нужен Python 3.10 или новее. Устанавливать ничего не нужно: всё, что нужно сборщику, лежит внутри файла.
:::

::: note
Если строки о сборщике в окне нет, сборщик не входит в вашу установку ArchMap. Обратитесь к администратору.
:::

## Запустить в репозитории

Чтобы собрать схему и факты, выполните следующие действия:

1. Положите файл `archmap-scan.pyz` в папку репозитория системы.
2. В папке репозитория выполните команду:

    ```bash
    python3 archmap-scan.pyz . --system "Ярмарка"
    ```

    Сборщик напечатает сводку и сложит результат в папку `archmap-scan/`.
3. Откройте файл `archmap-scan/summary.txt`. В нём перечислено, что найдено, что сборщик разобрать не умеет, какие папки исключены и как импортировать результат.

::: note
Ключи команды:

- `--system ИМЯ`: имя системы в схеме. Без ключа сборщик возьмёт имя из манифеста сборки или имя папки репозитория;
- `--out ПАПКА`: куда сложить результат, по умолчанию папка `archmap-scan` в текущей папке;
- `--exclude ШАБЛОН`: что не читать (например, `--exclude legacy/`). Ключ можно повторить.

Полный список ключей покажет команда `python3 archmap-scan.pyz --help`.
:::

::: note
Постоянные исключения можно записать в файл `.archmapignore` в корне репозитория: по шаблону на строку, как в `.gitignore`, но без строк с `!`. Папки с тестами, документацией и примерами сборщик пропускает сам и перечисляет в сводке.
:::

::: note
Сборщик не выполняет код репозитория, не обращается к сети и пишет только в папку результата. Чтобы результат не попал в репозиторий, добавьте папку `archmap-scan/` в `.gitignore`.
:::

::: note
Если папка результата уже есть и её создал не сборщик, он её не перезапишет и попросит указать другую папку ключом `--out`.
:::

## Импортировать схему

Чтобы создать проект по схеме сборщика, выполните следующие действия:

1. На экране **Проекты** нажмите кнопку **Новый проект** и выберите способ **Импорт**.
2. Добавьте в поле справа файл `archmap-scan/schema.yaml` (см. [Создать проект из архива или YAML](export-import.md#создать-проект-из-архива-или-yaml)). Под полем появится строка о том, что файл собран сборщиком фактов.
3. Введите название проекта в поле **Название**.
4. Дождитесь проверки и нажмите кнопку **Создать проект**.
5. Нажмите кнопку **Открыть проект**.

::: note
Чтобы обновить уже созданный проект по свежему коду, запустите сборщик снова и добавьте новый `schema.yaml` в окно **Обновить из кода** (см. [Обновить схему после изменений в коде](sync.md)).
:::

::: note
В схеме сборщика нет описаний и нет связей сверх тех, что видны в манифестах и коде. Объекты, связи которых сборщик не увидел, получат рекомендацию **Объекты без связей** (см. [Разобрать рекомендации к схеме](alerts.md)). Связи и описания можно дописать вручную (см. [Добавить связи между объектами](edges.md)) или поручить ИИ-агенту (см. [Импортировать схему, собранную агентом из кода](import-agent.md)).
:::

## Добавить факты

Чтобы добавить таблицы, параметры конфигурации и каналы, выполните следующие действия:

1. Откройте окно фактов нужного вида:
    - для файлов `*.tables.yaml`: на странице базы данных в разделе **Структура** нажмите **+ Таблица** и выберите **Через ИИ-агента** (см. [Описать структуру базы данных](db.md#agent));
    - для файлов `*.config.yaml`: на странице контейнера в разделе **Конфигурация** нажмите **+ Параметр** и выберите **Через ИИ-агента** (см. [Описать конфигурацию сервиса](config.md#agent));
    - для файлов `*.channels.yaml`: на странице брокера в разделе **Каналы** нажмите **+ Канал** и выберите **Через ИИ-агента** (см. [Описать каналы брокера](channels.md#agent)).
2. Добавьте в окно все файлы этого вида из папки `archmap-scan/facts/`. Под полем появится проверка.
3. Нажмите кнопку **Применить**.
4. Повторите шаги 1–3 для файлов других видов.

::: note
Сборщик пишет адрес объекта первой строкой каждого файла фактов, поэтому все файлы одного вида можно добавить в одно окно, открытое со страницы любой базы данных, контейнера или брокера. Описаний у таблиц, параметров и каналов нет, их можно дописать вручную или с помощью агента.
:::

::: note
Папку `archmap-scan/agent/` читает ИИ-агент: в ней основание каждой записи (файл и строка), точки входа и подсказки. ArchMap её не импортирует.
:::
