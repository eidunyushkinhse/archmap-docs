::: note
У каждой страницы объекта есть [статус документации](../glossary.md#status): **В работе** или **Согласовано**. Это статус самой страницы, а не объекта: статусы **Существует**, **Проектируется** и **Выводится** описывают жизненный цикл объекта (см. [Описать планируемые изменения системы](changes.md)). Новые объекты получают статус **В работе**.
:::

## Поставить статус странице

Чтобы поставить статус странице объекта, выполните следующие действия:

1. Откройте страницу объекта.
2. Рядом с именем объекта нажмите на статус страницы. Раскроется список из двух значений: **В работе** (страница ещё правится) и **Согласовано** (проверено редактором).
3. Выберите статус.

![Статус страницы](../images/status-pill.png "Статус страницы у имени объекта и список значений")

::: note
Правка документации статус не сбрасывает.
:::

## Проверить статус системы {#system}

::: note
Свой статус есть у контейнера, компонента и пользователя. У [системы](../glossary.md#system) своего статуса нет: она согласована, когда согласованы все вложенные в неё контейнеры и компоненты на любой глубине, в том числе внутри вложенных систем. Рядом с именем системы видно, сколько из них согласовано, например, **В работе · 2 из 5**.
:::

Чтобы найти несогласованные объекты системы, выполните следующие действия:

1. На странице системы нажмите на статус страницы рядом с именем. Раскроется список вложенных объектов с их статусами.
2. Нажмите на строку объекта. Откроется его страница, где статус можно поставить.

![Статус системы](../images/status-children.png "Статус системы со счётчиком и список вложенных объектов с их статусами")
