---
title: Объединить файлы из нескольких репозиториев в один проект
order: 5
---

::: note
Если система живёт в нескольких репозиториях, агент описывает каждый репозиторий отдельным файлом YAML. ArchMap объединяет такие файлы в один проект: объекты с одинаковым именем или одинаковым источником становятся одним объектом, а связи и компоненты из разных файлов собираются на нём. То, что объединение не может решить само, ArchMap спрашивает у вас.
:::

## Объединить файлы

Чтобы создать проект из нескольких файлов, выполните следующие действия:

1. Скопируйте промпт в окне **Новый проект** на способе **ИИ-агент** (см. [Импортировать схему, собранную агентом из кода](import-agent.md)).
2. Запустите агента с этим промптом в каждом репозитории системы. От каждого агента сохраните файл YAML.
3. В окне **Новый проект** добавьте все файлы в поле справа одним из способов:
    - перетащите файлы в поле все сразу;
    - нажмите кнопку **Загрузить файлы…** и выберите несколько файлов;
    - вставьте текст первого файла в поле, затем нажмите **+** над полем и вставьте следующий.
4. Дождитесь проверки. Если появилась строка **Не всё сошлось идеально**, ответьте на вопросы под ней (см. [Ответить на вопросы слияния](#questions)).
5. Нажмите кнопку **Создать проект**, а затем **Открыть проект**.

::: note
Каждый файл показан отдельной вкладкой над полем с номером и именем файла. Нажмите на вкладку, чтобы посмотреть файл; крестик на вкладке убирает файл.
:::

::: note
Промпт для всех репозиториев один и тот же: в нём заданы правила именования, по которым одинаковые объекты из разных файлов получают одинаковые имена. Не меняйте название системы между запусками.
:::

## Ответить на вопросы слияния {#questions}

Чтобы ответить на вопросы слияния, выполните следующие действия:

1. Под строкой **Не всё сошлось идеально** найдите блок **Без ваших решений не объединить**. В нём показан первый вопрос.
2. Если непонятно, откуда вопрос, раскройте строку **почему возник вопрос** под ним.
3. Выберите вариант ответа.
4. Нажмите **Дальше →**. На последнем вопросе кнопка называется **Завершить →**.
5. Когда вопросы закончатся, в блоке появится итог: **Разбор пройден** или **Осталось N вопросов без ответа**.

::: note
Ни один вопрос не обязателен: кнопка **Создать проект** активна всегда. Под каждым вопросом есть сноска **Если не отвечать, то …**: так ArchMap поступит без вашего ответа.
:::

::: note
К предыдущему вопросу ведёт кнопка **← Назад**, а к списку всех вопросов с вашими ответами ведёт кнопка **Все вопросы**. В итоге разбора кнопки **Вернуться к пропущенным** и **Пересмотреть ответы** открывают вопросы заново. Ответы сохраняются при любых переходах.
:::

::: note
Вопросы бывают такие:
- **разные значения поля**: у одного объекта в разных файлах разные описание, технология, роль, тип или статус. Выберите правильное значение;
- **связь в контейнер**: в одном файле у сервиса описаны компоненты, а в другом связь ведёт к самому сервису. Выберите компонент, с которым на самом деле связан объект, или **Оставить на контейнере «…»**;
- **объекты без связей**: группа объектов никак не связана с остальной схемой. Выберите **Провести связь** и укажите, с чем связан каждый объект, или **Оставить как есть**;
- **похожие имена**: два объекта названы почти одинаково (например, «Сервис заказов» и «Сервис заказа»). Выберите **Один объект** и задайте имя склеенного объекта или **Разные объекты**;
- **разное содержимое**: при импорте архивов одна и та же схема логики, спецификация, таблица, канал или параметр описаны по-разному. Выберите вариант; для схем логики есть **Добавить все**.
:::

::: note
ArchMap не добавляет связей и не склеивает объекты сам: это происходит только по вашим ответам. Ничего из файлов не удаляется.
:::

::: note
Свёртка **Придется подправить вручную** под вопросами перечисляет нестыковки, которые одним ответом не закрыть. Поправьте их в проекте после создания.
:::
