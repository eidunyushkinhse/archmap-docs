::: note
Архив проекта (zip) хранит всё знание проекта: схему, схемы логики, спецификации, структуры баз данных, каналы брокеров, конфигурацию и бизнес-процессы. Из архива можно создать проект заново (например, на другом сервере ArchMap) или догрузить его в существующий проект. Как скачать архив и YAML схемы, см. [Экспортировать проект](../user/export.md).
:::

## Создать проект из архива или YAML

Чтобы создать проект из архива или файла YAML, выполните следующие действия:

1. На экране **Проекты** нажмите кнопку **Новый проект**. Откроется окно **Новый проект**.
2. В поле **Название** введите название проекта. Если вы создаёте проект из одного архива, название и описание возьмутся из архива.
3. Выберите способ **Импорт**.
4. Добавьте файлы одним из способов:
    - перетащите файлы `.zip` или `.yaml` в окно;
    - нажмите **Выбрать файлы** и выберите файлы;
    - нажмите **Вставить текст** и вставьте текст YAML в поле.
5. Дождитесь проверки. Под файлами появится строка **Готово к импорту**, **Не всё сошлось идеально** или **Что-то пошло не так** (см. [Создать проект из YAML](import-agent.md#создать-проект-из-yaml)).
6. Нажмите кнопку **Создать проект**. В окне появится отчёт о том, что создано.
7. Нажмите кнопку **Открыть проект**.

::: note
Если добавить несколько файлов, ArchMap объединит их в один проект и, если нужно, задаст вопросы (см. [Объединить файлы из нескольких репозиториев в один проект](merge-repos.md)).
:::

::: note
У объекта с вложенными объектами в YAML укажите `element: system` или `element: container`, иначе ArchMap файл не примет. Остальное, что противоречит правилам типов, ArchMap поправит сам и перечислит в проверке.
:::

::: note
Размещение объектов по площадкам тоже входит в архив и в YAML (см. [Разместить объекты по площадкам](deployment.md)).
:::

::: note
Расположение объектов и участники в архив не попадают: ArchMap разложит схемы нового проекта заново, а его владельцем станете вы (см. [Открыть проект участникам и назначить роли](access.md)).
:::

## Догрузить архив в существующий проект

::: note
В существующий проект можно догрузить архив другого проекта: схемы объединятся, а вместе с ними перенесётся вся документация.
:::

Чтобы догрузить архив в проект, выполните следующие действия:

1. Откройте страницу проекта.
2. В правом верхнем углу нажмите кнопку **Действия со схемой** (три точки).
3. В меню выберите **Догрузить архив**. Откроется окно **Догрузить архив**.
4. Добавьте архивы одним из способов:
    - перетащите файлы `.zip` в окно;
    - нажмите **Выбрать файлы** и выберите файлы.
5. Дождитесь, пока ArchMap посчитает, что добавится. Под файлами появится сводка: сколько объектов, связей и документации добавится, какие объекты из архива ArchMap узнал в проекте и по чему, какие объекты будут созданы.
6. Если под сводкой есть вопросы, ответьте на них (см. [Устранить расхождения между файлами](merge-repos.md#questions)).
7. Нажмите кнопку **Применить**. В окне появится отчёт **Архивы догружены**.
8. Нажмите кнопку **Готово**.

::: note
Если документация в архиве и в проекте расходится (например, у одной схемы логики разный текст), ArchMap спросит, какой вариант оставить. Чтобы решить все такие вопросы разом, под вопросами нажмите **Оставить, как было в проекте** или **Взять из новых архивов**.
:::

::: note
Если, пока окно было открыто, проект изменили, ArchMap пересчитает сводку и попросит проверить её и нажать **Применить** ещё раз.
:::

::: note
Чтобы обновить проект по YAML от агента, а не по архиву, используйте пункт **Обновить из кода** (см. [Обновить схему после изменений в коде](sync.md)).
:::
