title: Открыть проект участникам и назначить роли

---

::: note
Новый проект видят только его создатель и администраторы. Чтобы с проектом работали другие, добавьте их участниками или откройте проект на чтение всем пользователям. Менять доступ может только владелец проекта.
:::

## Добавить участника

Чтобы добавить участника, выполните следующие действия:

1. На экране **Проекты** на карточке проекта нажмите кнопку **⋯**.
2. В меню выберите пункт **Доступ**. Откроется окно **Доступ к проекту**.
3. В поле **Добавить участника** введите логин пользователя. По мере ввода появятся подсказки.
4. Справа от поля выберите роль: **Редактор** или **Читатель**.
5. Нажмите кнопку **Добавить**. Пользователь появится в списке **Участники**.

::: note
Пользователю с общей ролью «Пользователь» можно дать только роль **Читатель**. Если ввести логин такого пользователя, под полем появится подсказка **«Пользователь» может быть только читателем**.
:::

::: note
Редактор тоже может открыть окно **Доступ к проекту**, но только чтобы посмотреть список участников.
:::

## Изменить роль или удалить участника

Чтобы изменить роль участника или удалить его из проекта, выполните следующие действия:

1. Откройте окно **Доступ к проекту**.
2. В списке **Участники** найдите пользователя и выполните одно из действий:
    - в списке справа от имени выберите новую роль;
    - нажмите кнопку **Удалить**.

    Изменение сохранится сразу.

## Открыть проект всем на чтение

Чтобы проект видели все пользователи сервиса, выполните следующие действия:

1. Откройте окно **Доступ к проекту**.
2. Установите флажок **Виден всем пользователям**. Пользователи, которые не участвуют в проекте, смогут его смотреть, но не менять.

::: note
Чтобы снова закрыть проект, снимите флажок. Участники проекта сохранят свои роли.
:::

## Передать владение

Чтобы передать проект другому архитектору, выполните следующие действия:

1. Откройте окно **Доступ к проекту**.
2. В строке владельца нажмите **Передать владение**. Под списком участников появится поле **Новый владелец**.
3. В поле **Новый владелец** выберите пользователя.
4. Нажмите кнопку **Передать**. Откроется окно подтверждения.
5. Нажмите **Передать**.

::: note
После передачи вы останетесь в проекте редактором. Владельцем можно сделать любого пользователя с общей ролью «Архитектор», даже если он ещё не участник проекта.
:::
