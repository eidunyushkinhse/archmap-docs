::: note
Администратор видит все проекты сервиса, в том числе закрытые и архивные, и в каждом действует как владелец. Это нужно, когда владелец проекта недоступен (например, уволился или заблокирован).
:::

## Передать проект другому владельцу

Чтобы передать чужой проект другому архитектору, выполните следующие действия:

1. На экране **Проекты** на карточке проекта нажмите кнопку **⋯**.
2. В меню выберите пункт **Доступ**. Откроется окно **Доступ к проекту**.
3. В строке владельца нажмите **Передать владение**.
4. В поле **Новый владелец** выберите пользователя.
5. Нажмите кнопку **Передать**. Откроется окно подтверждения.
6. Нажмите **Передать**.

::: note
Прежний владелец останется в проекте редактором. Если он больше не должен видеть проект, удалите его из участников в том же окне (см. [Изменить роль или удалить участника](../architect/access.md#изменить-роль-или-удалить-участника)).
:::

::: note
Передать владение можно только пользователю с общей ролью «Архитектор». Перед тем как понизить архитектора до пользователя, передайте все его проекты: владельца проектов понизить нельзя.
:::

## Восстановить проект из архива

Чтобы вернуть проект из архива, выполните следующие действия:

1. На экране **Проекты** откройте вкладку **Архив**. На ней видны архивные проекты всех пользователей.
2. На карточке проекта нажмите кнопку **⋯**.
3. В меню выберите пункт **Восстановить**. Откроется окно подтверждения.
4. Нажмите кнопку **Вернуть**.

::: note
Так же администратор может отправить в архив, удалить навсегда, переименовать проект или открыть его всем пользователям (см. [Архивировать, восстановить или удалить проект](../architect/archive.md), [Открыть проект участникам и назначить роли](../architect/access.md)).
:::
