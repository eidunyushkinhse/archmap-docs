::: note
Если пользователь забыл пароль, администратор задаёт ему новый на экране **Пользователи**. Старый пароль администратор не видит и узнать его не может.
:::

## Сбросить пароль

Чтобы сбросить пароль пользователя, выполните следующие действия:

1. Откройте экран **Пользователи** (см. [Открыть экран Пользователи](users.md#открыть-экран-пользователи)).
2. Справа в строке пользователя нажмите **Сбросить пароль**. Откроется окно **Сбросить пароль**.
3. В поле **Новый пароль** введите пароль не короче 8 символов.
4. Нажмите кнопку **Сбросить**.
5. Передайте пароль пользователю и попросите сменить его после входа (см. [Сменить пароль](../user/password.md)).

::: note
Свой пароль администратор меняет так же, как и все, в меню профиля. Если администратор не может войти, доступ восстанавливается серверной командой (см. [Восстановить доступ администратора](first-admin.md#восстановить-доступ-администратора)).
:::

::: note
Сброс пароля не закрывает открытые сессии пользователя и не отзывает токены его ИИ-агентов. Если учётной записью мог воспользоваться посторонний, заблокируйте её (см. [Заблокировать учётную запись](users.md#заблокировать-учётную-запись)), а после разблокировки попросите пользователя отозвать свои токены (см. [Отозвать токен](../user/agent-setup.md#отозвать-токен)).
:::
