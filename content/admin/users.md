---
title: Создать учётные записи и назначить роли

---

::: note
Учётные записи заводит администратор на экране **Пользователи**. Почты в ArchMap нет, поэтому временный пароль администратор передаёт человеку сам, а тот меняет его в меню профиля.
:::

## Открыть экран Пользователи

Чтобы открыть экран **Пользователи**, выполните следующие действия:

1. В правом верхнем углу любой страницы нажмите на кружок профиля. Откроется меню профиля.
2. В меню выберите **Пользователи**. Откроется экран со списком учётных записей: логин, роль, признак администратора, статус и дата создания.

::: note
Пункт **Пользователи** есть в меню только у администраторов.
:::

## Создать учётную запись

Чтобы создать учётную запись, выполните следующие действия:

1. На экране **Пользователи** нажмите кнопку **Новый пользователь**. Откроется окно **Новый пользователь**.
2. В поле **Логин** введите логин.
3. В списке **Роль** выберите общую роль:
    - **Архитектор**, если человек будет создавать проекты и править схемы;
    - **Пользователь**, если человеку нужно только читать документацию.
4. Если человек будет управлять учётными записями, установите флажок **Администратор**.
5. В поле **Временный пароль** введите пароль не короче 8 символов.
6. Нажмите кнопку **Создать**. Учётная запись появится в списке.
7. Передайте человеку логин и временный пароль. Попросите его сменить пароль после первого входа (см. [Сменить пароль](../user/password.md)).

::: note
Учётная запись сама по себе не открывает проекты: человек видит только проекты, куда его добавили участником, и проекты, открытые всем (см. [Открыть проект участникам и назначить роли](../architect/access.md)).
:::

## Изменить общую роль

Чтобы изменить общую роль пользователя, выполните следующие действия:

1. На экране **Пользователи** найдите пользователя.
2. В столбце **Роль** выберите новую роль. Изменение сохранится сразу.

::: note
Когда архитектор становится пользователем, его роли редактора в проектах меняются на читателя. Владельца проектов понизить нельзя, поэтому сначала передайте его проекты другому архитектору (см. [Передать проект или восстановить его из архива](projects.md)).
:::

::: note
Роль администратора изменить нельзя, потому что администратор всегда архитектор.
:::

## Выдать или снять права администратора

Чтобы выдать или снять права администратора, выполните следующие действия:

1. На экране **Пользователи** найдите пользователя.
2. Справа в строке пользователя нажмите одну из кнопок:
    - **Сделать админом**: пользователь сразу получит права администратора;
    - **Снять админа**: откроется окно подтверждения, в нём нажмите **Снять**.

::: note
Пользователь, ставший администратором, получает общую роль «Архитектор». После снятия прав администратора роль остаётся прежней. Снять права с себя или с последнего администратора нельзя.
:::

## Заблокировать учётную запись

Чтобы заблокировать учётную запись, выполните следующие действия:

1. На экране **Пользователи** найдите пользователя.
2. Справа в строке пользователя нажмите **Заблокировать**. Откроется окно подтверждения.
3. Нажмите **Заблокировать**. В столбце **Статус** появится **Заблокирован**.

::: note
Заблокированный пользователь не сможет войти, его открытые сессии закроются, а токены ИИ-агентов перестанут действовать. Удалить учётную запись нельзя, но её можно заблокировать.
:::

::: note
Чтобы вернуть доступ, нажмите в строке пользователя **Разблокировать**. Заблокировать себя или последнего администратора нельзя.
:::
