::: note
Сразу после установки в ArchMap нет ни одной учётной записи, а самостоятельной регистрации нет. Первого администратора создаёт серверная команда `archmap-admin create-admin`, а остальные учётные записи администратор заводит в интерфейсе (см. [Создать учётные записи и назначить роли](users.md)).
:::

## Создать администратора

Чтобы создать первого администратора, выполните следующие действия:

1. Выполните команду для своего способа установки, указав логин администратора (например, `admin`):
    - Docker Compose (в папке с файлом `compose.yaml`):

        ```bash
        docker compose exec archmap archmap-admin create-admin admin
        ```

    - Kubernetes:

        ```bash
        kubectl -n archmap exec -it deploy/archmap -c archmap -- archmap-admin create-admin admin
        ```

    - сервер:

        ```bash
        sudo archmap-admin create-admin admin
        ```

2. Введите пароль и повторите его. Команда ответит **Создан администратор «admin»**.
3. Откройте ArchMap в браузере и войдите с этим логином и паролем.

::: note
Пароль должен быть не короче 8 символов и не длиннее 72 байт (72 латинских символа или 36 русских букв). Пароль вводится только в консоли и в истории команд не остаётся.
:::

::: note
Если пользователь с таким логином уже есть, команда не создаёт нового, а делает существующего администратором: выдаёт ему общую роль «Архитектор» и снимает блокировку. Пароль при этом не меняется.
:::

## Восстановить доступ администратора

Чтобы вернуть доступ администратору, который забыл пароль или был заблокирован, выполните следующие действия:

1. Выполните команду `create-admin` с параметром `--reset-password` для своего способа установки (например, на сервере):

    ```bash
    sudo archmap-admin create-admin admin --reset-password
    ```

2. Введите новый пароль и повторите его.
3. Войдите в ArchMap с новым паролем.

::: note
Команда делает пользователя администратором, снимает блокировку и задаёт новый пароль. Пароли остальных пользователей сбрасывает администратор в интерфейсе (см. [Сбросить пароль пользователя](reset-password.md)).
:::
