::: note
Демо-режим превращает экземпляр ArchMap в открытый стенд для знакомства с продуктом. Вместо входа по логину посетитель нажимает **Попробовать без регистрации** и получает свою песочницу: временную учётную запись и копию демо-проекта «Маркетплейс «Ярмарка»». Песочница удаляется после суток бездействия. Включайте демо-режим только на отдельном экземпляре ArchMap с отдельной базой, а не на рабочем.
:::

## Включить демо-режим

Чтобы включить демо-режим на сервере, выполните следующие действия:

1. Установите ArchMap на отдельный сервер с отдельной базой (см. [Установить ArchMap на сервер](install-server.md)).
2. В файле `/etc/archmap/archmap.env` добавьте строки:

    ```bash
    DEMO_MODE=true
    ARCHMAP_WORKERS=1
    ```

3. Перезапустите службу:

    ```bash
    sudo systemctl restart archmap
    ```

4. Откройте адрес стенда и проверьте, что на экране входа появилась кнопка **Попробовать без регистрации**.

::: note
На демо-стенде нужен ровно один рабочий процесс: уборка песочниц и счётчик запусков с одного адреса работают внутри процесса. С двумя процессами уборка шла бы параллельно, а предел запусков удвоился бы.
:::

::: note
В Kubernetes задайте `DEMO_MODE=true` в значении `extraEnv`, а `config.workers` и `replicaCount` установите в `1`.
:::

## Что можно на демо-стенде

::: note
Гость может как угодно править свою копию демо-проекта и создать ещё один проект любым способом из окна **Новый проект**. Входа по логину, регистрации, участников проекта, смены пароля и экрана **Пользователи** на стенде нет. ИИ-агента к демо-стенду подключить нельзя: адрес `…/mcp` выключен, токены не выпускаются.
:::

::: note
Пределы для каждого проекта на стенде:

- объектов: до 100;
- связей: до 120;
- схем логики: до 75;
- бизнес-процессов: до 10;
- текста в проекте: до 250 КБ;
- загружаемый файл: до 250 КБ.

Удалять и сокращать можно всегда, даже если проект уже вышел за предел.
:::

::: note
Стенд одновременно держит до 300 песочниц и пускает с одного адреса до 10 новых песочниц в час. Эти пределы задают переменные `DEMO_MAX_SANDBOXES` и `DEMO_START_PER_IP_PER_HOUR`. Когда предел исчерпан, посетитель увидит **На демо сейчас слишком много пользователей. Попробуйте через час.**
:::

## Обслуживать демо-стенд

::: note
Администрирования в интерфейсе на демо-стенде нет: стенд обслуживается серверными командами.
:::

Чтобы проверить стенд и убрать песочницы, выполните следующие действия:

1. Посмотрите сводку по песочницам:

    ```bash
    sudo archmap-admin demo-stats
    ```

    Команда покажет, сколько живых песочниц и проектов у гостей и кто дольше всех без активности.

2. Если нужно, уберите песочницы без активности сразу, не дожидаясь плановой уборки:

    ```bash
    sudo archmap-admin demo-cleanup
    ```

    Чтобы задать свой срок бездействия, добавьте параметр `--idle-hours` (например, `--idle-hours 12`).

::: note
Плановая уборка идёт сама каждые 10 минут и удаляет гостей, неактивных дольше суток, вместе с их проектами. Обычные учётные записи она не трогает.
:::
